# OctoAcme Project Management Docs

This folder contains the core project management processes used by OctoAcme. Together, these documents provide a practical framework for validating ideas, planning delivery, managing execution, communicating with stakeholders, releasing changes, and capturing lessons for continuous improvement.

OctoAcme follows a simple lifecycle: initiate work by confirming the problem, stakeholders, success metrics, and decision to proceed; plan scope, backlog, dependencies, and milestones; execute with regular team rhythms, quality checks, and delivery tracking; manage risks and communication; release with verification and rollback planning; and close each effort with retrospectives that turn lessons into action.

## Project lifecycle and process docs

- [Project Management Overview](octoacme-project-management-overview.md) — High-level introduction to OctoAcme's roles, artifacts, lifecycle, and communication cadence.
- [Project Initiation Guide](octoacme-project-initiation.md) — Defines how to validate a project idea, align stakeholders, and create the initial plan and artifacts.
- [Project Planning](octoacme-project-planning.md) — Covers backlog prioritization, planning activities, estimates, milestones, and dependency/risk management.
- [Execution & Tracking](octoacme-execution-and-tracking.md) — Explains daily execution, review rhythms, blockers, quality expectations, and delivery metrics.
- [Risk Management & Communication](octoacme-risks-and-communication.md) — Details how to track risk, communicate status, and escalate issues appropriately.
- [Release & Deployment Guide](octoacme-release-and-deployment.md) — Standardizes pre-release checks, deployment steps, rollback paths, and release communication.
- [Retrospective & Continuous Improvement](octoacme-retrospective-and-continuous-improvement.md) — Shows how to run retrospectives and convert lessons into tracked improvements.
- [Roles & Personas](octoacme-roles-and-personas.md) — Describes the typical roles used across OctoAcme project documents and how they participate in delivery.

## How to use this folder

Use this README as the starting point for understanding how OctoAcme runs projects. Start with the Overview and Initiation docs for a new initiative, then move to Planning and Execution as work becomes concrete. Reference Risk Management, Release, and Retrospective guides as work progresses to keep delivery predictable and improvement-oriented.

## Core themes across the docs

- Clear ownership and accountability through defined roles and decision points
- Iterative delivery with measurable outcomes and regular feedback loops
- Communicated plans, risks, and interdependencies across teams and stakeholders
- Quality gates, testing, and deployment readiness built into delivery practices
- Continuous learning through retrospectives and action tracking
